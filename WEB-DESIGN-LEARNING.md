# Web Design Learning · Guia MER

## Dirección adoptada

- **Glassmorphism pedagógico + Bento + Motion**: superficie técnica sobria, acentos de color por estación y movimiento solo como retroalimentación de avance.
- **Ruta progresiva visible**: el aprendiz ve el hilo orientar → ejemplo → practicar → producir → transferir.
- **Zonas separadas**: explicación, simulador y artefacto tienen superficies distintas para no mezclar lectura con acción.
- **Copia local con límites**: los exportables se generan en el navegador y se etiquetan como borradores no oficiales.

## Patrones seleccionados

1. `pedagogical-glassmorphic-sidebar-hub` — orienta en una guía de seis estaciones y mantiene el progreso visible.
2. `example-template-application-transfer` — cada módulo tiene explicación, ejemplo interactivo y acción de transferencia.
3. `states-are-instruction` — anomalías, validaciones, estados vacíos y avisos de recuperación son parte del contenido.
4. `local-copyable-evidence-with-boundaries` — exporta Mermaid, SQL, Markdown y CSV sin cuenta ni datos remotos.

## Límites y evidencia pendiente

El primer recorrido se valida técnicamente en 320, 768, 1440 y 2560 px. La comprensión real requiere una persona aprendiz que no haya construido la página; la guía no afirma competencia por navegarla ni por acumular progreso.
